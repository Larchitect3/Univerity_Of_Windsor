Well there are a lot of little steps to learn. I have put together a brief presentation to help you get started... with an (almost) working solution.

Addendum: I have added a routine to test this code with all the input set. For this I created a test data generator to create input from 1 to 10000, and then a -1. Do the following steps:

gcc testgen

./a.out > in      this will create the input test data for all possible cases from 1 to 10000

gcc 11636.c -lm

./a.out < in > out      now look at the file called "out" and see if all the cases are correct.

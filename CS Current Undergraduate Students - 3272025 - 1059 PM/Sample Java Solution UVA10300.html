This is the solution that I did in today's class. Here is why I was getting a run-time error:

Java Console applications may only have one and only one Scanner. The problem in my code is that I declared a Scanner object in main() then I declared another Scanner object in ProcessCase(). The solution was to only declare the Scanner in main() then pass it as parameter to the ProcessCase().

Note also how I did the debugging in Java. I declared an interface to keep my global constants, including DEBUG. Then I use if (DEBUG) System.err.println() to display message. Note that I use err instead of out because the standard error is unbuffered output.

Note the input file: uva10300.in that contains the input text that you need to type to test the program. All the keystrokes are basically stored in this file. To make sure there are no funny characters in the input file do this: od -c uva10300.in

use the following to test the code:

java Main < uva10300.in
